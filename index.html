Hakkımda

Harran Üniversitesi Bilgisayar Mühendisliği mezunuyum. Yazılım geliştirme (Java / Spring Boot), sistem entegrasyonu ve ağ mimarileri alanlarında deneyim sahibiyim. Büyük ölçekli sağlık kurumlarında HBYS kurulum ve entegrasyonu, kurumsal Active Directory / Windows Server yönetimi, VoIP / Softswitch sistemleri ve Cisco ağ teknolojileri üzerinde çalıştım. Analitik düşünme, problem çözme ve takım çalışmasına yatkın bir mühendis olarak yazılım ve sistem mühendisliği alanlarında değer katmayı hedefliyorum.
