# Mehmet Kömürcüoğlu — Portfolyo

Kişisel portfolyo ve CV sitesi. GitHub Pages üzerinde yayınlanır.

- Site: https://mehmetkmrcoglu.github.io/
- CV (PDF): https://mehmetkmrcoglu.github.io/Mehmet_Komurcuoglu_CV.pdf

## İçerik

- index.html — tek sayfa portfolyo (hakkımda, deneyim, projeler, yetkinlikler, iletişim)
- styles.css — ekran görünümü ve A4 baskı stilleri
- script.js — kaydırma takibi ve yıl bilgisi
- profile.jpg — profil fotoğrafı
- Mehmet_Komurcuoglu_CV.pdf — yazdırmaya hazır 2 sayfalık A4 CV

## Yerelde çalıştırma

index.html dosyasını tarayıcıda açmak yeterlidir; derleme adımı yoktur.

## PDF üretimi

Sayfadaki "Yazdır / PDF" düğmesi tarayıcının yazdırma penceresini açar. A4 olarak kaydetmek için hedef olarak "PDF olarak kaydet" seçilir.
